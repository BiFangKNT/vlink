# vlink

Bash 视频硬链接工具。使用 Bash 4+ 及 Unix 命令行工具，覆盖目标时需要支持 `-T` 的 GNU `mv`。源与目标必须位于同一文件系统，目标目录需提前创建。

目录输入仅处理当前层级的 `.mp4`、`.mkv` 文件，不处理子目录中的文件；也可直接指定源文件。

```bash
bash link_video.sh --help
bash link_video.sh -op ./source                         # 预览
bash link_video.sh -op ./source -lp ./target -sn s01e01-s01e12
bash link_video.sh -undo                               # 撤销上次执行
```

默认模式在达到结束序号后停止。需要交互时，输入结束会停止执行并返回非零退出码；已经创建的路径仍写入运行记录，可用于撤销。链接创建失败时同样停止，失败路径不会计入记录；覆盖操作先创建临时硬链接，创建或替换失败时保留原目标。

撤销只删除记录中的文件，再从内到外清理已记录的空目录。非空目录会保留；如果有路径未能删除，返回非零退出码并保留运行记录，处理后可再次撤销。
