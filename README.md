# vlink

Bash 视频硬链接工具。使用 Bash 4+ 及 GNU 命令行工具，包括支持 `-z` 的 `sort`、支持 `-T` 的 `ln`、`mv` 和用于读取文件身份的 `stat`。源与目标必须位于同一文件系统，目标目录需提前创建。

目录输入仅处理当前层级的 `.mp4`、`.mkv` 文件，不处理子目录中的文件；也可直接指定源文件。

```bash
bash link_video.sh --help
bash link_video.sh -op ./source                         # 预览
bash link_video.sh -op ./source -lp ./target -sn s01e01-s01e12
bash link_video.sh -undo                               # 撤销上次执行
bash tests/regression.sh                               # 回归验证（需要 timeout）
```

位置参数依次为源路径、目标路径、可选序号及包含正则；目标目录不存在会报错。预览过滤使用 `-fi`、`-fe`，例如 `bash link_video.sh ./source -fe 'Special|OVA'`。正则匹配文件名（含后缀），使用 Bash 扩展正则且区分大小写；非法正则在创建前报错。

默认和快速模式在达到结束序号后停止。需要交互时，输入结束会停止执行并返回非零退出码。所有模式先创建临时硬链接、保存待提交记录，再发布目标；发布失败时保留已有目标。覆盖确认会替换原目标，撤销不会恢复被覆盖的内容。

创建前按过滤结果和序号范围检查整批源文件。目标目录当前层级有 1000 个及以下文件时，检查所有名称；超过 1000 个文件时，只检查队列按当前模式和序号生成的目标路径，异名硬链接不再触发提前退出。命中同一文件（设备号和 inode 相同）时，提示双方路径并立即退出，不创建链接或改写运行记录。检查只读取文件身份信息，不比较内容；预览不执行此检查。交互调整序号后的实际目标在发布前也会检查是否与源为同一文件。

运行记录存放在脚本所在目录的 `vlink_last_run.log`，待提交记录为 `vlink_last_run.log.pending`。记录使用版本头和空字符分隔对象路径、文件身份及类型，支持换行文件名。身份包含设备号、inode 和创建时间。

发布后若提交失败或执行中断，待提交记录用于恢复；存在待提交记录时，新创建任务会停止，请先执行 `-undo`。没有创建文件的执行不会清空已有记录。

撤销优先读取待提交记录，仅删除身份一致的对象，并清理已记录的临时对象及空临时目录。路径已被替换时保留当前对象、移除失效记录；身份读取或删除失败时保留撤销项，修复后可重试。

旧版按行记录及 `vlink-log-v1` 没有文件身份，无法确认对象归属，因此不再自动撤销；脚本会保留记录并提示手动核对。

创建与撤销共用脚本目录中的 `vlink_last_run.log.lock` 锁目录，覆盖记录读取、文件操作及提交全过程。同一脚本同时只允许一个修改任务；占用或无法创建锁时立即报错，预览可并行。正常退出、`SIGINT`、`SIGTERM` 会释放锁。

恢复范围限于已保存待提交记录的操作。`SIGKILL` 或断电可能留下锁，以及尚未记录的 `.vlink.*/link` 和日志临时文件；不承诺断电后的磁盘持久性，也不自动搜索或删除这些残留。确认原进程已经结束后，再手动核对、清理残留锁和未记录临时对象，然后使用 `-undo` 处理记录中的对象。撤销期间避免其他程序替换目标路径；身份核对与删除之间不提供跨程序原子性。
